# منصة الإرسال الذكي — WhatsApp Automation

أداة لإرسال رسايل واتساب (نص + صور + PDF) لقايمة أرقام، على دفعات وبهدوء.

## المميزات
- لصق الأرقام أو رفع ملف Excel / CSV، تنضيف وحذف المكرر، وتحويل للصيغة الدولية (الكويت +965 افتراضي، ومصر والسعودية والإمارات وقطر والبحرين وعُمان).
- طريقتين للربط:
  - **ربط بالكود زي واتساب ويب** (مجاني، Baileys). ⚠️ غير رسمي: ممكن واتساب يقيّد أو يحظر الرقم. ابعت لعملاءك بس.
  - **WhatsApp Cloud API الرسمي** من Meta (Token + Phone number ID من داخل الموقع).
- مرفقات: لحد 5 صور / فيديو / PDF (16 ميجا للصورة وPDF، 50 ميجا للفيديو)، والرسالة بتتبعت كتعليق على أول ملف.
- أمان الإرسال: دفعات، فواصل عشوائية، استراحة بين الدفعات، حد يومي، سطر إلغاء، وضع تجربة لأول كام رقم، وزر إيقاف.
- باسورد دخول (`APP_PASSWORD`).

## التشغيل على جهازك (ويندوز)
1. ثبّت Node.js LTS من nodejs.org
2. دبل كليك `install.bat` (مرة واحدة)
3. دبل كليك `start.bat` وافتح http://localhost:3000

## التشغيل أونلاين (Render)
1. اعمل حساب على render.com واربطه بـ GitHub.
2. New ← Blueprint ← اختار الريبو ده (هيقرا `render.yaml`).
3. اكتب `APP_PASSWORD` (8 حروف أو أكتر) لما يطلبه.
4. استنى الـ Deploy، وافتح اللينك اللي بيديهولك (`https://....onrender.com`).

ملحوظات:
- الخطة المجانية بتنام وبتمسح جلسة الربط، فلازم Starter (حوالي 7 دولار في الشهر) + Disk عشان الربط يفضل محفوظ.
- السيرفر مش هيشتغل أونلاين من غير `APP_PASSWORD`، عشان محدش يبعت من رقمك.
- بديل: أي VPS باستخدام الـ `Dockerfile` (اربط volume على `/data`).

## ملفات بتتحفظ في DATA_DIR (ومش بتترفع على GitHub)
`auth/` جلسة الواتساب · `config.json` بيانات الـ API · `usage.json` عداد اليوم · `link.log` سجل الربط
